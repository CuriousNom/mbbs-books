# 1st Year MBBS - Medical Biochemistry

Place Biochemistry textbooks (e.g., U. Satyanarayana, DM Vasudevan) in WebP format into subdirectories:
- `satyanarayana/`
- `vasudevan/`

### Adding new pages:
1. Convert PDF pages to WebP: `1.webp`, `2.webp`, ... `N.webp`
2. Update metadata in `assets/js/catalog.js` with `available: true` and `totalPages: N`.
