# 1st Year MBBS - Human Physiology

Place Physiology textbooks (e.g., Guyton and Hall, Ganong, AK Jain) in WebP format into subdirectories:
- `guyton-hall/`
- `ganong/`
- `ak-jain/`

### Adding new pages:
1. Convert PDF pages to WebP: `1.webp`, `2.webp`, ... `N.webp`
2. Update metadata in `assets/js/catalog.js` with `available: true` and `totalPages: N`.
